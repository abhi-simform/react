# Stage 0 checkpoint: model answers

1. **Why does View Source show an empty page in SPA mode?** The server returns only a static HTML shell (scripts, no content); React builds the DOM in the browser after the JS bundle downloads and runs. Trade-offs: first paint waits for JS (blank screen, slower on weak devices), crawlers and link previews that do not run JS see nothing, but hosting is trivial (static files/CDN) and navigation after load is instant.
2. **What does `VITE_` do, why is `VITE_RAZORPAY_KEY_SECRET` a bug?** Vite only exposes env vars with that prefix on `import.meta.env`, and it inlines them into the shipped JS. So the value is public to every visitor. A secret with that prefix leaks the secret; only the public `key_id` may be a `VITE_` variable, the secret stays on the server.
3. **CORS and credentials.** CORS is a browser-enforced policy: the browser blocks a page from reading a cross-origin response unless the server's `Access-Control-Allow-*` headers allow that origin; the server only declares the rule. Cookies on cross-origin requests are sent only with `credentials: "include"`, and the server must then respond with `Access-Control-Allow-Credentials: true` and an explicit origin (a `*` wildcard is rejected with credentials).
4. **First three Network-tab checks when an API call "does not work".** (a) Was the request sent at all, and to which URL/method (wrong base URL, CORS preflight failure)? (b) The status code (4xx vs 5xx vs blocked/cancelled). (c) The response body (error envelope `code`/`details`) and the request payload/headers (Authorization, content-type).
