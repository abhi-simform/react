# Checkpoint: explain it without notes (Stage 13)

1. **LCP / INP / CLS.** LCP = when the largest visible element (hero/card/gallery image or a text block) is painted, target <= 2.5 s; fix in ShopSphere: right-sized, prioritised first-row/hero image (`ResponsiveImage priority`, WebP, `srcset`) and preloaded font. INP = worst latency from an input to the next paint, target <= 200 ms; fix: `useTransition` for the 300-card quick filter (160 -> 48 ms at 4x CPU). CLS = unexpected layout movement, target <= 0.1; fix: the PDP loading state was a 60 px line so the footer jumped (0.52); a screen-tall skeleton took it to 0.014.
2. **`useTransition`.** It marks an update as non-urgent: React renders it in an interruptible, lower-priority pass so typing stays responsive, and gives `isPending`. It does NOT make the render faster or cheaper (the same work happens; there were even more commits); `memo`/the Compiler/virtualization do that.
3. **When virtualization is wrong.** Short lists (< ~100 simple rows), lists that need Ctrl+F, tab order across all rows, text selection or anchors, and rows that are slow to render for other reasons. Costs: find-in-page, focus loss, a11y bookkeeping (`aria-setsize/posinset`).
4. **Production build with throttling.** Dev builds are unminified, have StrictMode double renders and HMR, no code splitting parity; the desktop CPU/network hides what a mid-range phone feels. We measured the production build at 4x CPU / slow 4G.
5. **Service worker must never cache** authenticated or private responses (cart, orders, me, payments, notifications, wishlist) or any non-GET: another user on a shared device could read them, or a stale cart could be shown. Here: allow-list of public paths + no credentials header + server `Cache-Control: public`; an e2e checks Cache Storage.
6. **SPA mode and SEO.** Tags exist only after JavaScript runs: Googlebot renders it, link-preview bots do not (product cards show the generic site card). Mitigations: per-route meta, canonical without tracking params, JSON-LD, sitemap/robots, `noindex` for private pages, prerender for static routes; SSR (Stage 14) would put product tags in the HTML.
7. **Manual memoization to delete with the Compiler.** `memo(ProductGrid)` and `useMemo(shown)` were redundant (deleted). `memo(ProductCard)` + `useMemo(cards)` were NOT (a parent `.map` still creates fresh elements; removing them made the grid 5x slower), so they stay with a comment.
